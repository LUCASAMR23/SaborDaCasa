# Sabor da Casa

Aplicação responsiva de receitas que transforma inspiração em uma lista de compras simples. O projeto foi planejado em cinco entregas diárias, com uma evolução documentada em [docs/PLANO_DE_PRODUCAO.md](docs/PLANO_DE_PRODUCAO.md) e [docs/BACKLOG.md](docs/BACKLOG.md).

## Entrega atual — Dia 1

- Página inicial responsiva para celular e desktop
- Identidade visual, navegação, filtros e cards de receitas
- Estados de favoritos no navegador
- Hero autoral com imagem gerada para o projeto
- Prévia visual do planejamento e da futura lista de compras

## Tecnologias

- React + TypeScript
- Vite
- CSS responsivo sem bibliotecas visuais

## Rodar localmente

```bash
npm install
npm run dev
```

## Próxima entrega

No Dia 2, cada receita ganhará ingredientes, ajuste de porções e o botão funcional para adicionar itens à lista de compras.
