# Notas de acessibilidade

O fluxo de receitas foi revisado para manter as ações essenciais disponíveis por teclado.

- Todos os controles recebem indicador visual de foco.
- O modal de receita recebe foco no botão de fechar quando é aberto.
- A tecla `Escape` fecha o modal.
- Botões de favorito, porções, remoção e fechamento possuem nomes acessíveis.
- As mensagens de confirmação usam uma região de status para leitores de tela.

Na próxima revisão, o fluxo será testado manualmente com leitor de tela e navegação apenas por teclado, conforme o roteiro do Dia 2.
