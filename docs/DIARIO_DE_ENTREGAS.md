# Diário de entregas

Este arquivo registra o que mudou em cada etapa para que o projeto possa ser apresentado e retomado com clareza.

## Dia 1 — Fundação visual e descoberta

**Status: concluído**

### Entregue

- Criado o repositório Git local do projeto.
- Configurado React, TypeScript e Vite.
- Desenvolvida a página inicial com navegação, hero, cards e filtros.
- Criada a versão responsiva para celular e desktop.
- Implementado o estado de favoritos durante a sessão.
- Adicionada imagem autoral ao projeto.
- Criados plano de cinco dias, backlog e documentação técnica.

### Validado

- Filtros trocam o conjunto de receitas visíveis.
- Favoritos alternam visualmente ao toque/clique.
- Build de produção executado com sucesso usando `npm.cmd run build`.

### Ainda não faz parte da entrega

- Abrir uma receita completa.
- Adicionar ingredientes ao carrinho/lista.
- Persistir favoritos.
- Calcular preços.

## Dia 2 — Receita e lista de compras

**Status: concluído**

### Entregue

- Criado o modal de detalhes com ingredientes, preparo, tempo e categoria.
- Adicionado controle de porções, que recalcula as quantidades mostradas.
- Implementada lista de compras persistente no navegador.
- Itens de mesmo nome e unidade são consolidados ao adicionar mais de uma receita.
- Incluídos check-ins, remoção de itens, limpeza da lista e estados vazios.

### Validado

- Adicionar receitas atualiza a lista com quantidades proporcionais.
- A lista permanece após recarregar a página.
