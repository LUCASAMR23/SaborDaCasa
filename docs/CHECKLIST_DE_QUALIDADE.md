# Checklist de qualidade

## Antes de encerrar cada dia

- [ ] O escopo previsto para o dia está refletido no diário de entregas.
- [ ] O backlog foi atualizado quando uma história foi concluída ou teve seu escopo alterado.
- [ ] As interações novas funcionam com clique e teclado.
- [ ] A página continua utilizável em 360px, 768px e 1440px.
- [ ] Textos de botões explicam o que acontece ao acioná-los.
- [ ] Imagens têm texto alternativo adequado.
- [ ] Não há informação de preço apresentada como valor em tempo real.
- [ ] `npm.cmd run build` conclui sem erros.
- [ ] O commit descreve uma mudança real e tem uma mensagem clara.

## Fluxos que serão conferidos no Dia 5

1. Encontrar uma receita por categoria ou busca.
2. Abrir a receita e alterar o número de porções.
3. Adicionar ingredientes de mais de uma receita à lista.
4. Marcar e remover itens da lista.
5. Conferir a estimativa total e seu aviso de referência.
6. Recarregar a página e verificar os dados persistidos.
